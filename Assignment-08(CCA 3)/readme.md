## Final Conclusion Summary

### Study Overview
This comparative UX evaluation assessed our modified high-fidelity Figma prototype against the original HMT Watches website. Five participants (**Jasjyot Singh**, **Siddhant Deshmukh**, **Sahil Pawar**, **Arhaan Mulani**, and **Nikhil Karmare**) completed the same task on both versions using the **Think Aloud** method:

> **Task:** Find the Kohinoor Automatic, add it to the cart, and reach the delivery details step of checkout.

---

### Usability Challenges in the Original Website

| Usability Issue | Description | Participants Affected |
|---|---|:---:|
| **Outdated and cluttered layout** | Cluttered visual structure, dated typography, and no brand story or aesthetics | **5 / 5** |
| **Unclear stock and availability status** | Hard to confirm whether a model like the Kohinoor Automatic was in stock before going deep into checkout | **4 / 5** |
| **Ambiguous delivery timelines** | Difficulty finding estimated shipping dates and PIN code serviceability in early cart stages | **4 / 5** |
| **Convoluted navigation and search** | Extra steps to find collections, with limited instant search suggestions and model filtering | **3 / 5** |

---

### What the Redesigned Prototype Improved
Participants found the prototype significantly easier, faster, and more visually engaging. It introduced a modern dark-mode heritage design, intuitive sidebar filtering, persistent stock indicators, and a structured 4-step checkout progress flow. 

**Features participants appreciated:**
- **Immersive Hero Section:** Highlighting brand heritage (*"A Legacy, Wound by Hand Since 1961"*).
- **Quick-View Product Modal:** Displays clear mechanical specifications (*Movement, Case Diameter, Water Resistance*).
- **Slide-out Cart Drawer:** Features a live 5-minute stock reservation timer (*"Reserved for you: 04:16"*).
- **Instant PIN Code Checker (`560001`):** Shows real-time delivery estimates (*"Arriving by Tuesday, 24 June"*).
- **User Dashboard / Account Portal:** Visual order tracking stages (*"Stock Allocated"*, *"Preparing to Pack"*).

---

### Quantitative Evaluation Results

| Measure | Original Site | Redesigned Prototype |
|---|:---:|:---:|
| **Participants completing task** | — | **5 / 5** *(zero critical errors)* |
| **Task completion time** | Baseline | **Visibly reduced** |
| **18-parameter UX survey average** | **2.8 / 5.0** | **4.6 / 5.0** |

*The survey results strongly support the Think Aloud findings.*

---

### Recommended Further Improvements
- Fine-tune contrast ratios on mobile viewports
- Refine the micro-copy on filter options
- Add a guest checkout option

---

## Conclusion
The redesigned prototype successfully resolves the primary usability bottlenecks of the original platform. Minor usability tweaks during final responsive frontend development are recommended before full deployment.
